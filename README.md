# DOST

A small Windows desktop companion that learns what kind of encouragement fits, then offers helpful break reminders.

## Run locally

Install Node.js and npm, then run these commands from the project folder:

```powershell
npm install
npm start
```

The first build slice is an interaction preview for the cross-app companion. Use **Show companion preview** to display DOST over another app. The preview art is a static placeholder; expressive character animation will be added near the end of the build. Closing the main window keeps DOST in the Windows tray; choose **Quit DOST** from the tray menu to exit.

The incubation flow, locally personalized message selection, interval reminders, and optional fictional AI preview are added in later slices.
