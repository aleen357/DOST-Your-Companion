Architecture choices

Why these pieces?

Electron + plain web UI

One main process controls Windows windows and a separate renderer draws them. JavaScript stays the main language; the accepted cost is a larger app.

Tray-resident timer

Closing the main window hides Dost so scheduled reminders continue. Quit fully to stop it; the remaining time resumes on next launch.

Local guest file

One versioned JSON document (schema 7) keeps answers, scores, the message pack, sleep and follow-up state, and migrates older files.

Generation inside Let’s Go

If Ollama and the model are installed, one localhost call writes the pack; the output is validated as untrusted text. Otherwise DOST hatches with prepared lines, silently.

Honest reminder cadence

Habit nudge every two hours and a light line about every 50 minutes (two minutes and 50 seconds in demo). It measures time Dost runs, not screen use.

Two clear characters

Chill Dost is green. Bossy Dost is orange-red, direct but kind. Both animate in slime.js.

Demo contract

What the recording can show

Normal behavior

Three sessions 24 hours apart; habit nudge every two hours, light line about every 50 minutes.

Accelerated demo

npm run start:demo: 30-second incubation waits, two-minute habit and 50-second light lanes, five-minute light mute. Sleep stays five hours.

Local model setup

Install Ollama for Windows, run ollama pull qwen3.5:4b. Let’s Go uses it if present; generation takes one to two minutes.

The model needs an internet download once. After setup, answers are sent only to Ollama running on this computer.
