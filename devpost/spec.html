Architecture choices

Why these pieces?

Electron + plain web UI

One main process controls Windows windows and a separate renderer draws them. JavaScript stays the main language; the accepted cost is a larger app.

Tray-resident timer

Closing the main window hides Dost so scheduled reminders continue. Quit fully to stop it; the remaining interval resumes on next launch.

Local guest file

One versioned JSON document preserves answers, scores, local reminders, generated messages, and follow-up state across restarts.

Optional local generation

Ollama uses the guest's answers to make a personalized pack on this PC. Prepared messages are the fallback if the user skips or local generation is unavailable.

Honest reminder cadence

Two hours normally, two minutes in demo mode. It measures time Dost runs, not screen use. “Show reminder now” follows the real overlay path.

Two clear characters

Chill Dost is green. Bossy Dost is orange-red, direct but kind.

Demo contract

What the recording can show

Normal behavior

Three sessions separated by 24 hours; reminder after a two-hour running interval.

Accelerated demo

30-second incubation waits and a two-minute reminder interval. A visible test control can show the same overlay immediately.

Local model setup

Install Ollama for Windows and download the configured model. DOST checks for it and generates the message pack locally; the user can skip setup and hatch with prepared messages.

The model needs an internet download once. After setup, profile answers are sent only to Ollama running on this computer.
