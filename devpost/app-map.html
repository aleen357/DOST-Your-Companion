DOST app map

DOST is a Windows desktop companion for simple habits. It gathers light context during incubation, then offers local reminders, jokes, and encouragement through a small overlay. Feed and Sleep let the user care for the companion; Sleep pauses reminders until DOST wakes.

How a scheduled reminder reaches the screen

1. Timersrc/main/reminder-clock.js
arm() decides which lane is due.
→
2. Main processsrc/main/main.js
handleReminderDue(lane) gets a message and records it.
→
3. Message pickersrc/main/message-selection.js
selectReminder() chooses from the right lane.
→
4. Overlaysrc/renderer/overlay.js
renderReminder() shows the line and emotion.

The timer and message selection run in Electron’s main process. The overlay receives a presentation through the narrow preload bridge and updates its text and character.

Guided reference route

  1. Find the entry point

    In src/main/reminder-clock.js, open arm(). When a lane reaches its due time, it calls the supplied onDue(kind) callback.

  2. Follow the decision and save

    In src/main/main.js, resumeReminderClock() connects the timer to handleReminderDue. That handler calls selectReminder(guest, lane), stores the pending reminder, then calls presentReminder().

  3. See the visible result

    src/main/message-selection.js chooses an unused message from the habit or light lane. presentReminder() sends it to the overlay; src/renderer/overlay.js handles it in renderReminder().

The developer preview uses a fixed sample from previewPresentation(); it proves the overlay can render. Show reminder now triggers the reminder clock and follows the scheduling and selection path.

To change this, start here

Reminder timing

Start with the timing constants and resumeReminderClock() in src/main/main.js; the lane behavior is in src/main/reminder-clock.js.

Prepared fallback messages

src/shared/personas.js is the live prepared-message catalog and fallback, not a throwaway mock. src/main/message-selection.js decides which pool supplies a reminder.

Add a generated category

Define the category in src/main/dost-prompt.js, validate and map it in src/main/generated-pack.js, add prepared fallback lines in src/shared/personas.js, then route it in src/main/message-selection.js.

Character art and motion

Start with the emotion art in src/renderer/slime.js and its motion rules in src/renderer/styles.css.

Incubation questions

Start with src/shared/questions.js; src/renderer/incubation.js displays the flow and sends each answer through the preload bridge.

A practice to reuse

Give each stage one job: the clock decides when, the picker decides what, and the renderer decides how it appears. A new generated category crosses a similar boundary: prompt contract → response parser/mapper → selection, with prepared fallback content in the persona catalog. The preview-versus-scheduled distinction is another useful check: a preview verifies presentation, while a real timer path also exercises selection and saved state. On another project, trace one visible action across its trigger, decision, and output before changing a module.

Run it again

  • npm install installs dependencies.
  • npm start runs normal timing.
  • npm run start:demo shortens waits for a demo.
  • npm run start:dev adds developer preview and immediate reminder controls.
